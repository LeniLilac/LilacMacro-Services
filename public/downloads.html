SYSTEM / REQUIREMENTS

Before you install.

LilacMacro is a self-contained 64-bit Windows app. CPU OCR works everywhere the app is supported; a compatible NVIDIA GPU makes OCR faster.

01

Minimum

Supported baseline
OS
Windows 10 1903+ or Windows 11
Processor
64-bit x64 processor
Memory
8 GB RAM
Display
1366 × 768, Windows scale at 100%
OCR
CPU mode
Game
Roblox desktop app in windowed mode
02

Recommended

Smoother setup and OCR
OS
Windows 11 with current updates
Processor
Modern 6-core x64 processor
Memory
16 GB RAM
Display
1920 × 1080, Windows scale at 100%
OCR
NVIDIA GPU, compute capability 6.0+
Game
Roblox desktop app in windowed mode

RAM guidance is for one local session. Each additional Roblox session needs more system resources.
